Mijn vaardigheden

HTML

Basiskennis

Ik heb de basis van HTML geleerd en kan hiermee de structuur van een eenvoudige website maken. Ik kan onder andere werken met headings, paragrafen, afbeeldingen, links, tabellen en formulieren. Tijdens mijn opleiding wil ik mijn kennis van HTML verder uitbreiden.

CSS

In ontwikkeling

Met CSS leer ik hoe ik websites kan vormgeven. Ik kan bijvoorbeeld kleuren, afmetingen, marges en lettertypes aanpassen. Ook heb ik gewerkt met Flexbox om onderdelen van een website op de juiste plek te zetten. Ik wil hier steeds meer ervaring mee opdoen.

Programmeren

Beginner

Ik sta nog aan het begin van het leren programmeren. Tijdens mijn opleiding leer ik stap voor stap hoe programmeren werkt en hoe ik problemen logisch kan oplossen. Ik wil later verschillende programmeertalen leren en zelfstandig software kunnen ontwikkelen.
